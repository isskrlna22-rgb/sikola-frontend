# 📘 SIKOLA Project Overview

## Tentang Project

SIKOLA (Sistem Informasi Kehadiran & Layanan Akademik) adalah aplikasi web yang dirancang untuk membantu sekolah dalam mengelola kehadiran, informasi akademik, dan layanan akademik secara digital.

---

## Tujuan

- Digitalisasi absensi sekolah.
- Mempermudah akses informasi akademik.
- Mengurangi proses manual.
- Menjadi platform terintegrasi bagi siswa dan guru.

---

## Target Pengguna

- 👨‍🎓 Siswa
- 👩‍🏫 Guru
- 👨‍💼 Admin (Tahap berikutnya)

---
